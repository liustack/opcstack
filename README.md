# opcstack

**The one-person company skill stack.** Agent skills for solo founders (indie hackers, content creators, and consultants) covering business deconstruction, health checks, niche discovery, marketing diagnosis, and launch playbooks. Built on a dual foundation: the five-factor business framework (how to see a business) and the mental-model lattice applied to business decisions (how to decide, and how not to fool yourself), shared with [liustack](https://github.com/liustack/liustack), its thinking-and-dev sibling.

[中文](./README.zh-CN.md)

## Install

```bash
# Everything
npx -y skills add liustack/opcstack

# One skill
npx -y skills add liustack/opcstack --skill opc-niche
```

Claude Code marketplace:

```
/plugin marketplace add liustack/opcstack
/plugin install opcstack@opcstack
```

## Skills

| Skill | What it does |
|---|---|
| `opc-analysis` | Business deconstruction: role-model founders and benchmark products |
| `opc-checkup` | Business health check: cash-flow razor, lifespan pricing, unit economics, fatal dependencies |
| `opc-niche` | Niche discovery: find and score underserved markets |
| `opc-marketing` | Marketing diagnosis: locate your funnel bottleneck, ground the fix in human-nature theory |
| `opc-launch` | Launch playbook: goals, waitlist, staged channels, relaunch moves, hard pre-launch gate |

## Philosophy

Use opcstack directly, or (recommended) distill it into a playbook of your own. Use it, fork it, clone it: that is the intended path, rather than sending PRs. Questions and problems are welcome as issues, though I may not adopt every suggestion.
