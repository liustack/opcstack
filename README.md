# opcstack

**The one-person company skill stack.** Agent skills for solo founders — indie hackers, content creators, and consultants — covering business deconstruction, niche discovery, and marketing diagnosis. Built on the same five-element business framework and mental models as [liustack](https://github.com/liustack/liustack), its thinking-and-dev sibling.

## Install

```bash
# Everything
npx -y skills add liustack/opcstack

# One skill
npx -y skills add liustack/opcstack --skill opc-niche
```

Claude Code marketplace:

```
/plugin marketplace add liustack/opcstack
/plugin install opcstack@opcstack
```

## Skills

| Skill | What it does |
|---|---|
| `opc` | Router — hand it any business question, it picks the right skill |
| `opc-analyze` | Business deconstruction in three modes: role-model founders, benchmark products, health-check your own idea |
| `opc-niche` | Niche discovery — find and score underserved markets |
| `opc-marketing` | Marketing diagnosis — locate your funnel bottleneck, get routed to the right specialist skill |
