## AARRR → 技能映射（细版）

| 瓶颈环 | 首选 | 备选/进阶 |
|---|---|---|
| 测量缺失 | analytics | ab-testing（有流量后） |
| 获客·搜索内容 | seo-audit（先诊断）、content-strategy | programmatic-seo、ai-seo、schema、site-architecture、aso（移动端） |
| 获客·社媒 | social | video、image、sms |
| 获客·付费 | ads | ad-creative |
| 获客·外联发布 | launch（新品）、cold-email（B2B） | directory-submissions、public-relations、prospecting |
| 获客·工程化 | free-tools（免费工具做获客钩子） | lead-magnets |
| 激活 | onboarding、signup | cro、popups |
| 留存 | churn-prevention | emails（生命周期）、community-marketing |
| 推荐 | referrals | co-marketing、influencer-marketing |
| 收入 | pricing、offers | paywalls、sales-enablement（销售辅助）、revops（B2B 线索管理） |
| 用户理解（横切） | customer-research | marketing-psychology、competitor-profiling、competitors |
| 没思路要点子 | marketing-ideas | marketing-council（模拟顾问团） |

对方标注的技能链路（诊断后可作「下一步」建议）：customer-research → copywriting / cro / competitors。copywriting ↔ cro ↔ ab-testing。seo-audit ↔ schema ↔ ai-seo。

## Bullseye 的 19 个牵引力渠道（《Traction》，Gabriel Weinberg）

病毒营销、公关、非常规公关、搜索引擎营销（SEM）、社媒与展示广告、线下广告、SEO、内容营销、邮件营销、工程化营销（Engineering as Marketing）、垂直博客、商务拓展、销售、联盟计划、现有平台（利用应用商店/大平台）、展会、线下活动、演讲、社区建设。

三圈用法：外圈全过一遍强迫发散 → 中圈留 2–3 个有认知/竞品已验证的 → 内圈小成本测试后聚焦一个。
