# opc-niche：细分市场发现与评估

帮一人公司找到并评估细分市场。核心方法：多路独立信号交叉验证，再用评分卡逼出结论——单一信号（比如只看搜索量）是最常见的选错原因。

## 第一步：确认起点

先判断用户处于哪种状态，再走对应入口：

- **完全没方向** → 先问能力圈：你做过什么行业、懂什么人群、有什么别人没有的接触面？候选 niche 从能力圈与信号源的交集里找，不从热榜里找。用户已主动给出的信息不重复问，只补缺口。
- **已有候选要验证** → 直接进信号收集。
- 多个候选时逐个过，不并行比稀烂账。

## 第二步：信号收集（至少交叉两路）

四路信号源相互独立，完整操作步骤与工具清单见 `references/signals.md`。速查：

| 信号源 | 找什么 | 好信号 |
|---|---|---|
| 关键词流 | 低竞争度 + 购买意图的长尾词族 | SERP 前排是小博客/论坛帖/过时页面，而非权威站 |
| 社区挖掘 | 垂直社区里「讨厌某个工作流程」的帖子 | 同一痛点反复出现、发帖人已在用胶水方案凑合 |
| 竞品缺口 | G2/Capterra/App Store 的一二星差评 | 差评集中指向同一个被忽视的需求 |
| 趋势 | 新兴话题的早期信号 | 趋势工具发现 + Google Trends 真实搜索量验证，二者同向 |

硬规则：**至少两路信号同向才算候选成立**。只有一路时，结论上限是「值得再收集一路信号」，不是 go。

## 第三步：AI 红海测试（2025–2026 特化）

产品核心功能依赖模型推理（生成、分类、归因、摘要等）即算 AI 相关，拿不准就从宽判定。相关时必做三问：

1. **品类测试**：是否属于通用 wrapper 品类（写作助手、聊天机器人、会议摘要）？2025 年以来倒闭的 AI 创业公司几乎全部集中在这些横向品类。是 → 直接红旗，除非有极强的垂直限定。
2. **真实人力成本测试**：它替代的是哪一笔可衡量的人力开支（某岗位年薪、某专业服务时薪）？答不上来 → 价值主张存疑。
3. **窗口期测试**：数精确细分买家群体内的已融资竞品——少于 5 个是空白，少于 10 个是新兴。同时看有没有 2025–2026 的催化事件（监管截止日、技术解锁）。窗口期玩法（如低竞争词 + 程序化 SEO）是时效性套利不是永久壁垒，评估时要问：窗口关闭前能否建起反链/域名权重/数据这类可积累护城河。

## 第四步：五维评分卡

每维 0–10 打分。此评分结构是行业趋同实践，无单一权威出处：

| 维度 | 打分要点 |
|---|---|
| 市场规模 | 一人公司甜蜜点约 2 万–20 万潜在买家。太大养不起获客，太小养不起产品 |
| 竞争度 | 竞品「小、老、体验差、无风投」= 高分。已有融资巨头盘踞 = 低分 |
| 变现潜力 | 客单价区间与形态。优先能做成一次性付费/低维护的形态，高维护订阅对一人公司是持续客服负担 |
| 可触达性 | 能否用 SEO/社区/目录站低成本触达？要拼付费投放的 niche 对一人公司不友好 |
| 时机 | 增长中还是停滞？有无窗口期与催化事件 |

**判定规则**：任一维 < 4 即红旗——不是放弃，是先收窄再重打（例：「记账软件」变现与触达低分 → 收窄为「房产经纪的成交会议 AI 记录」后竞争与变现分数跳升）。收窄两次仍有红旗才是 no-go。

## 第五步：五要素复核与输出

评分通过后用五要素问一遍底层问题：人为什么掏钱（人性）、谁掌握议价权（结构）、是一次性套利还是复利资产（时间）、单点依赖在哪（风险）、价值是否远大于成本（价值）。

输出报告：候选描述 / 信号证据（注明每条来源与核实状态）/ 红海测试结果 / 评分卡 / 五要素复核 / **结论：go、收窄重评或 no-go** / 下一步建议（go 时建议用 opc-analyze 的 check 模式做完整商业体检）。

## 硬规则

- 搜索量、竞争度、竞品融资等外部事实：能联网核实就核实，不能就标注「未核实」，不要编造数字——**数量级估算（「大概几万」）也算编造**，一律标注。
- 评分卡分数是主观判断量表，不属于外部事实。但支撑打分的依据里凡未核实的事实须标注，且**零路信号核实时不得给出 go/no-go**，只能输出「核实计划 + 各信号的判定标准」。
- 来源是营销型内容站（卖 idea 数据库、卖课页面）时，标注来源性质，其数据只作参考不作依据。
- 结论用概率语气（大概率/倾向于/需验证），评分卡是逼问工具不是真理。
